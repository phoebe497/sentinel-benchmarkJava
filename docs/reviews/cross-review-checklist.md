# Cross-review checklist

Reviewer có 5 phút để trả lời:

- Nhìn root có phân biệt được code, dataset, test, report và raw artifact không?
- Chạy quick start có build được index và mở UI không?
- Report có tách rõ quá trình và kết quả, trong khoảng một trang A4 không?
- Mọi số liệu trong report có đường dẫn về JSON/JSONL/manifest không?
- Active data có hoàn toàn là BenchmarkJava, không lẫn WebGoat không?
- Mở [live demo](https://sentinel-benchmarkjava.streamlit.app/) bằng cửa sổ ẩn danh: ứng dụng có vào thẳng giao diện, trả HTTP thành công và hiển thị đúng phạm vi 100 file không?

Ghi kết quả review thành file ngày tháng trong thư mục này; không sửa report đã nộp để che lịch sử.
